# R02 metatheory and trusted-root inventory

The following are precise obligations, not claimed checked generic theorems.
The implementation and finite reference checks exercise them; discharge remains
under the existing R02/R04/R16 goals. No new inference rule accepts the statements
below merely because they are listed here.

## Semantic assumptions

A signature supplies mathematical total functions and predicates over its stated
sorts. First-order terms do not invoke Shen functions with matching names.
Equality is identity within each sort; the constructive interpretation uses
persistent predicates and rigid term interpretation across Kripke worlds.
User sorts have their specified domains, with the chosen standard nonempty-sort
interpretation. No implicit rule can synthesize a term from mere nonemptiness.

`vor.tree` denotes the finite initial algebra generated by leaf and binary node.
This well-founded interpretation is a root premise. Its induction rule is
unavailable for user sorts. No axiom of unrestricted recursion, classical
excluded middle, or consistency of the checker is introduced.

The fixed root consists of the rule dispatcher in kernel/proof.shen, the typed
formation and binding operations in spec/logic.shen, the literal decoder and
System S integration, and the unchanged trusted Shen/host execution stack.
An artifact cannot replace this dispatcher or supply a new side condition.
Changing these definitions changes the trusted release, even with the same
human-readable root label. R01 labels are not executable measurements.

## Formation, substitution, and context obligations

Write `Sig; V |- t : S` for term formation and `Sig; V |- P` for formula
formation. V is nearest-variable first. All source and result objects are finite.

1. **Signature adequacy.** Accepted signatures have distinct declared names,
   defined argument/result sorts, fixed arities, and no extension/redefinition
   of the reserved finite-tree constructors or sort.
2. **Formation decidability and adequacy.** The validators terminate on finite
   data and accept exactly the stated grammar, sorting, arity, and index rules.
3. **Weakening.** Inserting fresh sorts at a scope boundary and raising free
   indices at that boundary preserves term/formula formation. The binder-aware
   cutoff must preserve variables bound inside the formula. Context weakening
   applies the same operation to every hypothesis.
4. **Substitution.** If `Sig; S::V |- P` and `Sig; V |- t : S`, then the
   binder-removing result `P[t]` is formed under V. Replacements lifted below
   inner binders retain their free references; outer indices decrement exactly
   once after removing the distinguished binder.
5. **Substitution semantics.** Interpreting P[t] under environment rho equals
   interpreting P under the environment extended by the interpretation of t.
   For formulas this statement must hold at each world of the chosen
   constructive semantics, not merely for classical Boolean truth tables.
6. **Goal formation.** Every generated premise of a well-formed expanded rule
   has a well-formed variable scope, context, and target. This includes the
   two-variable tree-induction step and the shifted conclusion of exists-elim.

## Per-rule local soundness obligations

For every fixed rule, if its input sequent is formed, its side conditions hold,
and all generated premises are valid, its conclusion follows in the stated
constructive semantics.

| Rule family | Critical obligation |
| --- | --- |
| Hypothesis / truth | Exact context membership, no fabricated assumption; top is valid |
| Conjunction | Both premises for introduction; correctly annotated projections |
| Implication | The introduced premise stays branch-local; application uses the exact antecedent |
| Disjunction | One valid introduced branch; elimination proves the same result in both branches |
| Bottom | Explosion requires an actual derivation of bottom |
| Universal | Generalization introduces a fresh variable and raises old assumptions; instantiation is sorted and capture-avoiding |
| Existential | Introduction supplies a sorted witness; elimination raises the external target so its fresh witness cannot escape |
| Equality | Reflexivity is sorted identity; symmetry/transitivity preserve endpoints; substitution uses one correctly scoped motive and the exact equality |
| Tree induction | Leaf case, both child hypotheses, correctly raised outer context, and the finite-algebra induction premise |

Hypothesis contexts are reusable intuitionistic assumptions, not linear resources
or external authorizations. Deriving an implication from an impossible context
is logically valid and does not establish a real-world permission.

## Checker termination and acceptance soundness

For a well-formed sequent, finite proof object E, and natural Fuel <= 65535:

- Expansion checks a fixed rule and constructs a finite ordered premise list.
- Each invocation of derive consumes one unit before checking premises.
- Premises share the remaining fuel; proving one branch cannot reset fuel for
  the next branch. The returned remainder cannot exceed the supplied remainder.
- Zero fuel yields uncertainty. Malformed/unrecognized rules cannot yield proved.
- All syntax operations and annotation validators used in expansion terminate
  on their stated finite domains.

These statements support a fuel/structural termination argument and the intended
acceptance theorem: an accepted derivation entails the input sequent relative
to the fixed root semantics. The generic machine-checked proofs of these claims
are not implemented. A host process can still exhaust memory/stack or die;
proof-node fuel is not a proof of bounded physical resource usage.

The public indexed System S judgments additionally require a correspondence
proof for literal decoding, explicit checking, and inference. The typed API
prechecks its evidence and propagates uncertainty; it does not turn the
System S side-condition dispatcher into a second independent kernel.

## Finite syntax and derivation induction

The reserved tree algebra is a foundation for representing finite program
syntax and derivation trees. R03/R04/R16 must supply:

- The precise encoding of each finite syntactic constructor/tag/payload.
- Encoding validity and representation independence where claimed.
- Well-formedness predicates and correspondence with admitted syntax.
- Induction restricted to those encodings, with the correct recursive premises.
- Preservation between encoded reasoning and the actual Shen checker/evaluator.

The tree induction primitive alone proves none of those correspondences. It
does not establish the consistency of its own root logic. Artifact self-checking
cannot remove these premises.

## Independent reference evidence

The classical finite evaluator in tests/first-order-reference.shen uses direct
environment interpretation; it never calls the checker, term typer, or binder
operations to interpret a formula. It enumerates 256 assignments to the two
unary predicates and one binary predicate over a two-element domain. Accepted
rule-corpus sequents are checked under every matching free-variable environment.

The same interpreter checks the semantic substitution equation and weakening
across six nested formula templates, five replacement terms, four environments,
and those 256 interpretations. Formation is checked once per resulting formula,
not repeatedly counted for each interpretation.

The independent Kripke interpreter uses two ordered worlds, constant two-element
domains, rigid functions/equality, and 81 monotone valuations of four unary
predicate facts. Implication and forall quantify over future worlds. It checks
accepted rule-corpus sequents at both worlds, and gives countermodels for
excluded middle and double-negation elimination.

The finite tree quotient used in these tests is leaf=0 and
node(l,r)=(l+r+1) mod 2. Every element is constructor-generated, so it exercises
the induction rule's preservation cases. It is not the free initial algebra
and does not validate constructor disjointness/injectivity or encoding theorems.
These finite families are independent bug-finding evidence, not a universal
constructive soundness proof or an independent verification of the host.


## Optional checked scheduler and quantifier-free metatheory

budget. audit/rocq/Checker.v proves derivation construction, budget remainder and
extension, and semantic soundness conditional on local expansion soundness.
audit/rocq/Propositional.v proves all eleven quantifier-free constructive local
